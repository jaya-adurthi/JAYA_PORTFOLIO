## 🚀 Key Features

- **3D Interactive Project Flip Cards**: Smooth 3D Y-axis flip cards displaying project banners, details, and 3 functional action buttons (`Code`, `Live Website / Demo`, `Demo Video`).
- **Hero Typing Role Animation**: Letter-by-letter typing animation cycling between `Software Engineer` and `Frontend Developer` with a blinking cursor.
- **`Available for Work` Status Badge**: Clean status indicator displaying current availability for developer opportunities.
- **Theme Persistence**: Light and Dark mode switcher persisting user preferences in `localStorage`.
- **Fixed Navigation Dock**: Floating glassmorphic bottom bar for quick navigation, social links, and theme toggling.
- **Fully Responsive**: Mobile-first architecture ensuring seamless rendering on mobile, tablet, and desktop screens.

## 💻 Getting Started Locally

### Prerequisites
- [Node.js](https://nodejs.org/) (v16.0.0 or higher)
- `npm` or `yarn`

### Installation

1. **Clone the Repository**
   ```bash
   git clone https://github.com/jaya-adurthi/JAYA_PORTFOLIO.git
   cd JAYA_PORTFOLIO
   ```

2. **Install Dependencies**
   ```bash
   npm install
   ```

3. **Start Development Server**
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173` in your browser.

4. **Build for Production**
   ```bash
   npm run build
   ```
